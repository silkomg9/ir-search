# 제주특별자치도 지원사업/공모/교육 소스 조사

조사일: 2026-09-07
담당 범위: 제주특별자치도 (도 본청, 제주시·서귀포시, 산하 공공기관/재단/센터)

**핵심 요약**
- 도·시 본청 공식 사이트(jeju.go.kr, jejusi.go.kr, seogwipo.go.kr)는 robots.txt 차단 또는 JS 렌더링으로 자동 수집이 까다로움. jeju.go.kr은 `/news/` 계열 전체가 robots.txt 허용 목록 밖에 있어 크롤링 시 정책 위반 소지가 있으므로 별도 허가나 API 확인이 필요함.
- 반면 제주청년센터(jejuyouth.com), 제주소통협력센터(jejusotong.kr), 제주콘텐츠진흥원(ofjeju.kr), 제주경제통상진흥원(jba.or.kr), 제주여성가족연구원(jewfri.kr), 제주사회적경제지원센터(jejuhub.org) 등 **산하기관·중간지원조직 사이트가 오히려 서버렌더링 + 명확한 페이지네이션 + 높은 갱신 빈도**를 갖춰 실질적으로 더 쓸만한 소스임. 특히 jejuyouth.com·jejusotong.kr·ofjeju.kr는 여러 타기관 공고를 사람이 큐레이션해 재게시하는 "허브형" 게시판이라 커버리지 대비 효율이 높음.
- 제주마을만들기종합지원센터(jejumaeul.or.kr)는 403 차단으로 직접 접근 불가했고, 제주문화예술재단(jfac.kr)·사회복지공동모금회 제주지회(jeju.chest.or.kr)는 WebFetch로 실제 콘텐츠 확인에 실패해 재조사가 필요함.

## 1. 제주특별자치도 입법·고시·공고

- **운영기관**: 제주특별자치도 (본청)
- **목록 URL**: https://www.jeju.go.kr/news/news/law.htm (타기관 고시공고: https://www.jeju.go.kr/news/news/differ.htm)
- **대상**: 개인/모임/비영리법인/협동조합 모두 해당 가능 (도정 전반 고시공고이므로 지원사업 공고가 섞여 나옴)
- **내용 유형**: 고시·공고 전반 (개발행위, 인허가부터 지원사업 공모까지 혼재)
- **공고 빈도·최근성**: 미확인 (WebFetch 시점에 "검색된 데이터 없음"으로 표시됨 — JS 렌더링 이후 로드되는 것으로 추정, 실제 게시물 유무 미확인)
- **기술 접근성**: **JS 클라이언트 렌더링(SPA)** — 서버 HTML에는 게시글이 없고 JS로 동적 로드됨. 페이지네이션은 템플릿 변수(`{{ p }}`) 형태로 확인, 실제 파라미터 미확인. RSS/오픈API 여부 미확인.
- **robots.txt**: `https://www.jeju.go.kr/robots.txt` — **기본 전체 차단(Disallow: /)**, 허용 경로는 `/jori/ /jejueo/ /jedu/ /jejuingu/ /livingpopulation/ /workation/ /move/ /lifecycle/ /is/ /artist/` 뿐이며 **`/news/`(고시공고 포함)는 허용 목록에 없음** → 크롤링 시 robots.txt 위반 소지 있음, 별도 확인·허가 필요.
- **유용성 평가**: 중 — 도 전체 공식 고시공고 소스로서 커버리지는 필수적이지만, JS 렌더링 + robots.txt 차단이라는 이중 장벽으로 스크래핑 난이도가 높음. API 등 우회 경로 확인 필요.

- **유용성 평가**: 중 — 시 단위 공고 소스로 필요하나 실제 목록 페이지 구조·페이지네이션 확인이 더 필요함.
