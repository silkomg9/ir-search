## 15. 시·군 공고 접근법 — 통합 조회 사이트 없음, "새올(정보공개)" 표준 템플릿 다수 확인
- 결론: 경기도 31개 시·군 공고를 한 번에 모아 보는 공식 통합 포털은 검색상 확인되지 않음(미확인/없음으로 판단). 경기데이터드림(data.gg.go.kr)에 시·군 공고 통합 데이터셋이 있는지도 "고시공고" 키워드로는 못 찾음(위 2번 참조, 추가 키워드로 재확인 권장).
- 다만 다수 시·군이 동일한 "새올행정정보시스템" 계열 공고 게시판 URL 패턴을 사용하는 것으로 확인됨:
  - 패턴 A (`saeol/gosi/view.do?notAncmtMgtNo=...&mId=...`): 광주시(gjcity.go.kr), 과천시(gccity.go.kr) 등에서 확인
  - 패턴 B (`link/BD_notice.do`, `BD_bidding.do` 등 "BD_" 접두 URL): 고양시(goyang.go.kr) — 정보공개 > 공고 > 고시/공고/입찰공고/채용공고로 세분화됨. WebFetch로 메뉴 존재는 확인했으나 실제 목록 렌더링 내용(JS 로딩 여부)은 검색 결과 코멘트상 "내부 행정포털에서 데이터 로드, 시간 소요 가능" — 미확인/추가 검증 필요
  - 수원시(suwon.go.kr): `saeallOfr/BD_ofrList.do` — WebFetch로 메뉴 링크 확인됨(정상 접근), 단 목록 페이지의 실제 게시글·날짜·페이지네이션 파라미터는 이번 조사에서 텍스트로 확인되지 않음(미확인)
  - 성남시: 미확인(이번 조사에서 URL 미검증)
- 기술 접근성 종합: 시·군은 기관마다 CMS가 다르나(새올 계열이 많음), 도 산하기관보다 파라미터 규칙성이 낮고 개인/모임 대상 지원사업 정보는 "고시·공고"보다 별도의 "복지/문화/청년" 게시판에 더 많을 가능성이 있음 — 이번 조사 범위(고시공고 게시판 위주)만으로는 지원사업 포착률이 낮을 수 있음.
- 유용성: 하중 — 시·군 개별 접근은 31개 사이트를 각각 파악해야 하는 구조로, 스킬 자동화 관점에서는 우선순위가 낮음. 대신 경기도 산하기관(2~14번)과 도 청년포털이 시·군 사업의 일부를 재공지하는 경우가 많아 우선 활용을 권장.
